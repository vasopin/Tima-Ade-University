## Key Features Across All Pages

### Universal Components
1. **Header**: University logo, main navigation, mobile menu toggle, portal login, apply button
2. **Hero Section**: Large background, page title, description, primary CTA
3. **Breadcrumb Navigation**: Home > Current Page (except on homepage)
4. **Main Content**: Page-specific sections with cards, grids, or lists
5. **Footer**: 6-column layout with university info, links, portals, contact, legal

### Common Sections
- **Hero Section** with CTA
- **Featured/Highlighted Content** (featured news, events, programs, etc)
- **Statistics/Metrics** (where applicable)
- **Call-to-Action** sections throughout
- **Related Links/Navigation** to other pages
- **Contact/Get Involved** CTA at bottom

### Design Patterns
- **Card-based layout** for news, events, jobs, scholarships
- **Grid layouts** for statistics, programs, alumni stories
- **Timeline format** for history, events
- **Directory/List format** for faculty, staff, resources
- **Form elements** for contact, registration, applications

## Content Standards Applied

### Writing Style
- Professional yet approachable tone
- Clear value proposition for each section
- Action-oriented language in CTAs
- Authentic, specific details (not generic Lorem ipsum)

### Information Architecture
- Clear sections with h2/h3 headings
- Logical progression from general to specific
- Related information grouped together
- Multiple paths to find related content

### Visual Hierarchy
- Large h1 titles for page identity
- Prominent statistics and key metrics
- Visual distinction between section types
- Color coding for categories (where applicable)

### Interactive Elements
- Buttons for primary CTAs (Apply, Register, Learn More)
- Links for secondary navigation
- Form inputs for registrations/applications
- Hover states for interactivity feedback

### File Locations
```
frontend/pages/
  ├── about.tsx
  ├── alumni.tsx
  ├── careers.tsx
  ├── events.tsx
  ├── leadership.tsx
  ├── library.tsx
  ├── news.tsx
  ├── research.tsx
  ├── scholarships.tsx
  └── student-life.tsx

frontend/src/layouts/
  └── PublicLayout.tsx (navigation and footer)
```

### Component Imports Used
- **Layout**: PublicLayout (site wrapper with header, nav, footer)
- **Animations**: Reveal component (scroll-triggered fade-in)
- **Icons**: Lucide React icons
- **Styling**: Tailwind CSS utility classes

### Key Design Tokens
- **Primary Color**: Primary-700/900 (rose shades)
- **Text Dark**: Slate-900
- **Text Light**: Slate-300/white
- **Backgrounds**: Slate-50/950
- **Accent**: Rose-500/600

### Common Sections Pattern
```tsx
<section className="py-16 md:py-24 bg-[color]">
  <div className="container-xl">
    <Reveal>
      <h2 className="text-3xl md:text-4xl font-bold">Section Title</h2>
      <p className="text-lg text-slate-600 mt-4">Description</p>
    </Reveal>
    {/* Content grid/cards */}
  </div>
</section>
```
